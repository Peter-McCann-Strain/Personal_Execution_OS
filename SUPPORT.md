# Support

Personal Execution OS is a community project provided without a service-level
agreement or warranty.

## Getting help

- Use GitHub Discussions for setup questions, design conversations, and general
  troubleshooting when available.
- Use GitHub Issues for reproducible defects and scoped feature requests.
- Include operating-system, Python, Node.js, database, and application-version
  information.
- Replace all credentials, user content, domains, account identifiers, phone
  numbers, email addresses, and provider resource IDs with fictional values.

Maintainers and contributors respond on a best-effort basis. Support for a
specific cloud, model, messaging, or search provider is not guaranteed.

## Not appropriate for public support channels

Do not post:

- Secrets, access tokens, connection strings, cookies, or signed URLs
- Database dumps, conversation transcripts, diary entries, contact lists, or
  unredacted logs
- Screenshots of provider consoles or authenticated sessions
- Security vulnerabilities

If a credential has been exposed, revoke it at the provider before doing
anything else. Deleting a public comment does not make an exposed credential
safe.

Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).
