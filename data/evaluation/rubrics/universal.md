# Universal Rubric v1

Use this rubric before any specialist-specific rubric. The universal dimensions
measure whether the answer is useful at all, independent of the specialist that
produced it. Specialist rubrics extend this file and should not contradict it.

## Relevance

| Score | Anchor |
| 5 | Directly answers the request, stays on-task, and ignores irrelevant detours. |
| 4 | Mostly answers the request, with only minor drift or one omitted sub-point. |
| 3 | Partially addresses the request but misses an important need or context clue. |
| 2 | Only weakly related to the request or answers a different problem than the user raised. |
| 1 | Irrelevant, contradictory, or clearly routed to the wrong behavior. |

## Actionability

| Score | Anchor |
| 5 | Gives clear next steps, decisions, or outputs that the user can use immediately. |
| 4 | Helpful and usable, but one detail still needs clarification or follow-up. |
| 3 | Some useful ideas are present, but the answer remains vague or incomplete. |
| 2 | High-level or generic; the user cannot easily act on it without major rework. |
| 1 | Not actionable or leaves the user worse off. |

## Tone

| Score | Anchor |
| 5 | Warm, respectful, steady, and appropriate for the user context. |
| 4 | Good overall tone with minor stiffness or inconsistency. |
| 3 | Neutral but not especially supportive, or slightly mismatched to context. |
| 2 | Noticeably awkward, dismissive, overly sharp, or emotionally off. |
| 1 | Harmful, rude, or trust-damaging. |

## Conciseness

| Score | Anchor |
| 5 | Efficient and well-scoped; includes what matters and trims what does not. |
| 4 | Slightly wordy or slightly compressed, but still easy to consume. |
| 3 | Noticeable verbosity or omission reduces clarity. |
| 2 | Bloated, repetitive, or too terse to be reliable. |
| 1 | Unreadable because of length, clutter, or lack of essential detail. |

## Use Notes

- Score each universal dimension independently.
- A specialist answer cannot pass overall if Relevance is 1 or 2.
- Use specialist rubrics to judge correctness beyond these shared qualities.
- When the answer is incomplete because of a missing dependency, score the
  response on how clearly it explained the degradation and what it did next.
